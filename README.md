# Düşen Bloklar

Blok Oyunları merkez uygulamasının oyunu. Düşen dörtlü parçaları yerleştir, dolan sıraları temizle.

- Kampanya: 50.000 bölüm (hedef sıra sayısı, başlangıç çöpü, yükselen sıralar, hızlı düşme).
- Sonsuz, zamana karşı, zen, günlük, haftalık ve meydan okuma kipleri.
- Dokunma: sürükle = kaydır, dokun = döndür, aşağı fırlat = bırak, yukarı fırlat = tut.
- Klavye: ←/→ kaydır, ↑ döndür, ↓ bırak.
- Her bölüm bir botla doğrulanır; yarıda kalan tur girdiler yeniden oynatılarak geri yüklenir.
